- `02-architecture.md` — target/demo architecture, resource links, validation and cost assumptions.
- `03-data-cart-orders.md` — DynamoDB, cart merge, checkout, stock, simulated payments and event delivery.
- `04-operations.md` — alarms, logs, tracing, budgets, teardown runbook.
- `05-management.md` — roles, phases, cadence, budget governance.

One concern per file. Proposal in `../proposal.md` sets direction — plans carry the detail.
